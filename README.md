# ✅ ToDoList App — Lista de Tarefas com Kivy

Um aplicativo simples de **lista de tarefas** desenvolvido em **Python** com o **framework Kivy**.  
O ToDoList permite adicionar, marcar e desmarcar tarefas concluídas, salvando tudo automaticamente em um arquivo local `tasks.json`.

---

## 🧩 Funcionalidades

- ➕ Adicionar novas tarefas  
- ✅ Marcar e desmarcar tarefas concluídas  
- 💾 Salvamento automático em `tasks.json`  
- 🔁 Carregamento das tarefas ao abrir o app  
- 📱 Interface simulando uma tela de celular (414x736)

---

# ✅ Como Rodar o Aplicativo ToDoList com Kivy

Siga este passo a passo para instalar e executar o aplicativo **ToDoList** do zero no seu computador:

```bash
# 1️⃣ Instalar o Python
# Acesse https://www.python.org/downloads/
# Baixe e instale o Python 3.8 ou superior
# Durante a instalação, marque a opção "Add Python to PATH"
python --version        # Verifique se o Python foi instalado corretamente

# 2️⃣ Instalar o Kivy
pip install kivy        # Instala o framework usado na interface do aplicativo

# 3️⃣ Criar o projeto
# Crie uma pasta chamada "todolist" e abra no VS Code (ou outro editor)
mkdir todolist
cd todolist

# 4️⃣ Criar o arquivo principal
# Dentro da pasta, crie um arquivo chamado "main.py"
# Copie e cole o código abaixo e salve:

# 5️⃣ Executar o aplicativo
python main.py

# 🪄 O app abrirá em uma janela de 414x736 pixels simulando uma tela de celular.
# Você poderá adicionar tarefas, marcar como concluídas e todas serão salvas em "tasks.json".
