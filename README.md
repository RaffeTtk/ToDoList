# ToDoList
O código cria um app de lista de tarefas com Kivy. Ele define o tamanho da janela, permite adicionar, marcar e remover tarefas, e salva tudo em um arquivo JSON chamado “tasks.json”. Ao iniciar, o app carrega as tarefas salvas, exibindo-as na interface. É um gerenciador simples com salvamento local.
